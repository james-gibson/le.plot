# The reader

You have found one of these sites, and the obvious next question is what else exists. The map
answers it without asking you to clone anything.

## Start here

Open [the map](/#map). Twenty-six rows in three layers: eight deployments, twelve lab systems and six
reading tools. Each row names a readiness (or a kind), a front door (or what it provides)
and its parents or dependencies. Select a table for its record, or follow the row to its page.

## What the readiness column is for

Readiness, not seniority. A rung-0 reader wants a website and a bill and will not open a terminal;
a rung-3 reader delegates the running. The plot has both, and the column exists so nobody is
handed a shell prompt when they asked what a thing is.

The lab rows use a different column — `kind`, one of library, tool, app, upstream — because
"which language is it" is a different question from "how much of the machine does it assume". 

## What this seed refuses

- **A course.** There is no order to read the seed pages in beyond the ladder, and no exercises.
- **Screenshots.** Every sample on this site is the live component, because a picture of a diagram
  is not a diagram.
- **A claim you cannot check.** Each row links to the repository it describes. If a row is wrong,
  the fix is a commit.
