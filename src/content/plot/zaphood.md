# zaphood

The Office of Z.B. is a child seed of `le.gume`, and it is a joke: a homepage built to break every
polite rule of the internet. A marquee. A blink. A tiled background. A visitor counter. A webring.
An under-construction banner. An awards page the Office gave itself.

Underneath, it is the same content model, the same derived navigation, the same prerender and the
same publish gate. That is the point. The pattern survives a taste you would not defend.

## What it changed

| Part | Change |
| --- | --- |
| Sections | `about`, `awards`, `guestbook`, `links` — none of the starter's |
| Components | a library installed the way a 1998 tutorial would, then used on purpose |
| Rules | vendors `rules.md` at `29d863e`, with `RULES-06` overridden |
| Register | the first person, and a fictional office that is delighted to see you |

## What it proves

That "a seed, not a theme" is not a slogan. The house style is a decision, not a property of the
stack: `le.go` replaced the visual layer with a brick manual, `zaphood` replaced it with a
geocities board, and both still ship as the same kind of object.

## What it costs

- **A parody has a shelf life.** The joke is specific to a decade, and a page that is funny in
  2026 will read as a broken layout in 2030 unless someone keeps the intention visible.
- **Accessibility fights the premise.** A marquee, a blink and a low-contrast tiled background are
  three things a guard would normally refuse. The site keeps its waivers on the record rather than
  pretending they pass.
- **A guestbook without a server.** There is nowhere for a signature to go, so the guestbook is an
  exhibit, not a feature — and it says so.
