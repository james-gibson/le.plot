# le.gume

Six rows in this plot are sites made of the same parts, and this is where the parts come from. The plot has seven more rows that are not sites at all — the lab they describe.

`le.gume` is a documentation site whose content is Markdown files, whose navigation is derived
from the file tree, whose build refuses to publish when the output contradicts the source, and
whose deploy is a push to GitHub Pages. The trick is not that it is small. The trick is that
**the thing it documents is itself**, so every claim on its 60-odd pages has a file behind it.

## What it hands down

| Part | Why a child keeps it |
| --- | --- |
| `src/lib/content.ts` | One glob, one frontmatter parser, one derived navigation. Replace it and you replace the site |
| `src/lib/markdown.tsx` | The article voice, element by element |
| `scripts/verify-publish.mjs` | The gate. A page that is not in the bundle, a link that is not a route, a base path that disagrees with the mount |
| `scripts/postbuild.mjs` | Route shells, `404.html`, `llms.txt`, the sitemap — the parts Pages needs and Vite does not know about |
| `rules.md` | Nine rules with stable ids, generated by the build, so a child can vendor them and diff them |

## What it costs

Seven sections and sixty pages is a *starter*'s surface area, not a site's. Most of it is
argument about documentation, which is the starter's subject and rarely a child's. Every child
below had to run the inherited-page audit and delete what it could not re-derive; two of them
deleted entire sections.

A clone that keeps everything inherits an argument it does not make. That is the failure mode
this plot exists to make visible, one row at a time.
